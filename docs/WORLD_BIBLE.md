# 《从红月开始》World Bible

**版本：** v0.2 · 原文副本核对版

**状态：** 已根据用户提供的 TXT 副本核对开篇设定；副本版本来源尚未与正式出版版本交叉验证。

**用途：** 建立概念 Pilot 的设定核对框架，约束编剧、分镜、视觉设计与审片，不扩写原著百科。

## 1. 设定状态与证据规则

本资料核对了用户提供压缩包中的 TXT 副本。它自称“校对版全本”，包内还带有免费小说下载站来源信息；文件内容可直接复核，但版本完整性、授权来源和与正式出版文本的一致性尚未独立确认。下列标记用于所有设定、分镜和资产说明：

| 标记 | 含义 | 可以怎样使用 |
|---|---|---|
| `PROMPT_ONLY` | 用户在项目构想中提供，尚未与原文核对 | 可作为研究问题，不作为原著事实对外陈述 |
| `TEXT_CONFIRMED_IN_COPY` | 能在当前用户提供的 TXT 副本中定位到对应章节/场景 | 可用于本项目内部核对；引用时注明副本与章节，不宣称版本已获权威认证 |
| `SOURCE_PENDING` | 需要章节、页码或其他可靠原文位置支持 | 不得据此发明能力规则、对白或剧情因果 |
| `CREATIVE_PROPOSAL` | 本项目提出的视觉/剪辑表达，不声称来自原著 | 可用于内部概念验证；与故事事实分开标注 |
| `DECISION_NEEDED` | 需要项目负责人决定 | 冻结前必须补充决定及理由 |
| `VERIFIED` | 与权威/许可文本核对，且由负责人确认 | 可进入锁定版 Bible；记录来源与版本 |

### 来源记录格式

每项关键设定采用以下记录；来源可以是小说卷/章/段落定位，不必在制作文件复制大段原文。

```text
ID：WB-XXX
陈述：
状态：PROMPT_ONLY / SOURCE_PENDING / CREATIVE_PROPOSAL / DECISION_NEEDED / VERIFIED
来源：作品版本、卷/章、位置或链接（无则写“未提供”）
适用范围：全季 / Pilot / 单镜头
冲突与限制：
确认人 / 日期：
```

当前若干条目已达到 `TEXT_CONFIRMED_IN_COPY`，但没有条目达到 `VERIFIED`。后续若取得正式或授权版本，再核对关键事实与可见性；不能用同名动画的演绎替代小说依据。

## 2. 当前项目范围

- **交付目标：** 一个约 90 秒、以第一章《回家》为叙事锚点的 AI 动画开场概念 Pilot，验证红月城市、家庭反差、主角表演与外部观察视角。
- **叙事定位：** 以第一章《回家》为锚点的高概念悬疑/心理恐怖开场提案；全季事件线与后续设定不在本版范围内。
- **本版不是：** 逐字复述或逐场景照搬的章节稿、正式分集剧本、成片、官方动画复刻，亦不是授权声明。
- **不可越过的事实边界：** 不补写角色经历、能力原理、污染规则、组织职责、对白和事件结局；分镜中暂拟内容须标 `CREATIVE_PROPOSAL`。第一章未展示的咖啡馆事件和蜘蛛系战斗不塞进这个开场段。

## 4. Pilot 的观众信息边界

以下节奏依第一章《回家》压缩提炼；其剪辑、构图与不加对白的处理属于 `CREATIVE_PROPOSAL`，不是原著分镜：

1. 先用红月通勤和温暖室内建立日常，不在开头就给家庭行为贴“污染”标签。
2. 玩具、厨房、电话、餐桌等日常行为逐步变得不协调；由表演和剪辑承载悬念，不靠旁白解释。
3. 陆辛仍以日常方式与家人互动，并在冲突中平静吃饭；不要擅自演成他已经确认异常或恐惧失控。
4. 结尾切至观察者视角，揭示此场景里外部人员看到他独处；不要以此回答所有观察者能否看见家人。
5. 暂不揭晓家人的完整本体、精神异变机制或后续能力分类。

| 时间段 | 拟让观众感知 | 拟暂缓揭示 |
|---|---|---|
| 00–30 秒 | 红月下的城市通勤；陆辛回到住所 | 世界的完整历史、城市正式名称 |
| 30–47 秒 | 屋内温暖日常；家人依次出现 | 家人身份谜底与精神机制 |
| 47–66 秒 | 玩具、厨房、母亲离开后返回 | 邻居事件经过与血迹来源 |
| 66–85 秒 | 家庭冲突；妹妹攀上天花板；陆辛继续吃饭 | 冲突的暴力细节、行为背后原因 |
| 85–90 秒 | 外部观察视角看到陆辛独处及屋内扰动 | 所有角色的可见性规则、家人本体谜底 |

## 5. 世界规则的制作接口

每条原著规则须能翻译为制作可执行的约束；场景依据至少标注到章节与段落锚点：

- **触发：** 哪个事件令异常开始？镜头中能观察到什么？
- **主体：** 谁感知到它，谁没有？观众视角是否与某个人物绑定？
- **空间：** 哪些景物会受影响，影响边界怎样保持连续？
- **时间：** 异常持续多久，跨镜头时如何延续或复位？
- **行动：** 人物能够做什么、不能做什么；呈现效果需要哪些前置条件？
- **证据：** 对应章节、段落和确认记录。第一章外部观察只证明该场景中的观察者看见陆辛独处；第七章“二号看见妹妹”已足以阻止把它推广为全书绝对规律。

没有原文依据的答案写 `TBD`，而不是以生成模型常见视觉套路填空。

- Pilot 中的每条故事事实都有副本章节/场景定位，或明确为非故事性的视觉提案；正式锁定时须决定是否进行授权版本复核。

- 所有镜头的叙事揭示均不超出此版本允许的信息边界。
- 版本、来源和改编权限状态都有记录；状态不明时只用于内部验证。
