1. 先完成家中平面图、角色立绘和四个关键空间：列车、老楼楼道、家中全景、望远镜观察视角。
2. 做 90 秒 Animatic，固定 25 镜时长；镜头时长相加必须为 90 秒，再试听临时声音节奏。
3. 先测试 RM-009–018 的“暖室内日常 → 细节不协调 → 血迹回归”连续段，再测试 RM-021–025 的冲突与观察视角反转。
4. 动画按镜头分别制作关键帧/短片段，记录参考资产、提示词、工作流/模型版本、参数、种子、输出哈希和修订原因。模型/工作流能否在目标硬件运行仍需单独验证。
5. 审核分开记录：故事事实/来源、角色一致性、静帧构图、连续运动、声音体验、技术完整性。静帧抽样、时长计算或波形检查均不能替代完整连续观看与试听。
6. 任何实质改动都使受影响镜头的原审核结论失效；返修后检查该镜头及前后衔接。

## 7. Gate 与通过标准

| Gate | 通过条件 | 失败处理 |
|---|---|---|
| `G0` 来源/范围 | 镜头事实可定位到第一章场景锚点；提案与文本事实分开 | 记录差异并改镜头，不把创意补充说成原著内容 |
| `G1` 节奏 | 时间码从 00:00 连续至 01:30、25 镜合计 90 秒 | 重排/修正时长后重新计算 |
| `G2` 视觉资产 | 多色霓虹/暗红月亮、冷走廊/暖居室、玩具熊/衣服等识别物一致 | 返修指定资产与镜头，更新版本 |
| `G3` Animatic | 家庭日常到观察视角的情绪转折可读，行为因果不混乱 | 修改镜序或镜头时长，不扩量生成 |
| `G4` 音频技术 | 音轨完整、无削波、时间轴/文件时长对齐；本版确认没有可辨对白及虚假口型通过 | 保留技术失败项；返修音频后重跑受影响检查 |
| `G5` 影音感知审听 | 连续观看并试听全段；确认视角、环境声、留白和主题动机有效，无开放 `HARD/MAJOR` | 保持 `NEEDS_REVIEW`；分项标明未验证听感，不能用数字指标代替 |
| `G6` 交付 | 结论绑定最终视听文件哈希；发行/改编权限状态由项目负责人确认 | 保持 `NEEDS_REVIEW`，不标记为成片通过 |
