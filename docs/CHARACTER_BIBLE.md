# 《从红月开始》Character Bible

**版本：** v0.2 · 原文副本核对版

**状态：** 已核对用户提供 TXT 副本第一至七章中的角色信息；副本出版版本尚未认证。外形资产仍未定稿。

**用途：** 建立角色档案字段、表演边界和参考图制作清单，供分镜与视觉测试共同引用。

## 1. 角色资料状态与来源

本文件的角色依据来自 `../../1-2203151F522.zip` 内 TXT《从红月开始》（校对版全本）作者：黑山老鬼；GBK/CP936 解码；ZIP SHA-256：`611A8B71474F1E03E395334F060EBFE42CCC157D46C2725193B1E9B88325A1C3`。章节/场景锚点用于复查，不复制长段原文。此副本的版本、授权来源尚未独立认证。**含第一至七章情节信息。**

| 标记 | 含义 |
|---|---|
| `PROMPT_ONLY` | 由用户项目构想提到，尚未核对原文 |
| `TEXT_CONFIRMED_IN_COPY` | 在本轮用户提供的 TXT 副本中找到明确章节依据 |
| `SOURCE_PENDING` | 需要原著或可信授权设定资料确认 |
| `CREATIVE_PROPOSAL` | 本项目提出的表演/镜头方向，不是角色设定事实 |
| `TBD` | 当前不能安全推断，等待原文、设计或负责人决定 |
| `APPROVED` | 设计稿经负责人确认，并绑定参考资产版本 |

文本描述可以是 `TEXT_CONFIRMED_IN_COPY`，但这不等于视觉设计 `APPROVED`。目前没有角色视觉资产达到 `APPROVED`。镜头语法仅作为 `CREATIVE_PROPOSAL`，不得代替角色性格、能力和关系的原文依据。

## 4. 文本确认的角色锚点与视觉提案

### `CHAR-LUXIN` · 陆辛

- **文本锚点：** 第一章《回家》开篇，他乘环城列车回家；第二章在办公室工作，愿意帮同事整理文件；第五章人物档案记为 23 岁、评估 C 级、精神异变方向为蜘蛛系。第三章/第四章行动中表现出身体控制能力。以上均为 `TEXT_CONFIRMED_IN_COPY`，并非视觉定稿。
- **文本表演锚点：** 第一章在家人争吵/房间混乱时仍平静吃饭；这一反差可供本段表演设计。不得据此将他简化为“没有情感”或删去后续章节中的其他情绪表现。
- **视觉提案：** 此前讨论中的“瘦、安静、疲惫、普通衣着、眼神平”等仍全部是 `CREATIVE_PROPOSAL`，文本锚点不足以确认这些外貌特征。
- **待定资产：** 发型、脸型、身材、服装、年龄视觉表现、包袋、工作环境细节与三视图。
- **引用锚点：** 第一章通勤/回家、家庭餐桌与外部望远镜观察；第二章办公室帮助同事；第五章个人资料档案；第六章蜘蛛系能力解释。

### `CHAR-SISTER` · 妹妹

- **文本锚点：** 第一章称呼为妹妹，陆辛以“小十七”称她；她抱玩具熊、撕咬/拆开玩具，之后又把玩具缝回；在家庭冲突时攀至天花板。第三章地铁遭遇中，她协助陆辛摆脱控制。以上动作来自不同场景，不应误剪成开篇同一连续事件。
- **可见性：** 第一章的外部观察者没有看到她；第七章“二号”对妹妹有所回应。结论是“第一章的观测视角未看见”，不是“只有陆辛能看见”。完整机制 `SOURCE_PENDING`。
- **视觉提案：** 此前的墙面/天花板、低机位、广角和快速移动与第一章“攀至天花板”相容，但仍是镜头选择，不是固定角色标签；具体外形需从授权参考资料确认。
- **待定资产：** 年龄/身高比例、脸部、发型、服装、玩具熊版本、动作边界及不同观察者下的画面呈现。
- **引用锚点：** 第一章进门迎接/玩具熊/天花板场景；第三章地铁站妹妹协助；第七章“二号”看见妹妹的对话。

### `CHAR-MOTHER` · 妈妈

- **文本锚点：** 第一章首次出场穿白色羊毛开襟衫、站在窗边打电话；以温和、优雅的外在方式互动。之后离开住所，再返回时衣领处出现新鲜血迹；家庭冲突中仍有从容的语言表现。只表现文本可见事件，不推断其真实身份或精神性质。
- **视觉提案：** “对称、中长焦、镜面、剪影”仍是 `CREATIVE_PROPOSAL`；“优雅”有开篇叙述依据，但不可扩写为统一性格结论。
- **制作要求：** 开篇分镜安排她出场；固定服装须处理原文中白色/灰色羊毛衫提及之间的具体场景连续性，分镜选用“初次进门时白色”与“归来时原文描述的衣领血迹”两个锚点，并待设定审校确认颜色是否为同一件。

### `CHAR-FATHER` · 爸爸

- **文本锚点：** 第一章在厨房炖煮、剁骨，身穿塑料围裙；后续家庭冲突中动作强烈。以上是场景行为，不等于角色固定身材、怪物形态或道德判断。
- **视觉提案：** 此前“黑暗、遮挡、极近特写、低频震动”仍属 `CREATIVE_PROPOSAL`，不作为角色固有镜头语法。
- **制作要求：** 开篇分镜安排其出场；第一版采用厨房道具、声音与影子表达动作，不展示未经审定的怪物化身体细节。

### `CHAR-CHENJING` · 陈菁

- **文本锚点：** 第二章出现在办公室并与陆辛的工作任务有关；第五章副本中的身份介绍写作“青城主城/青城巡视厅”，第七章参与招募/评估谈话。由于书中大量使用“青港”而“青城”只出现在该身份段的两次重复，城市名列为副本内部待核差异，不在 Bible 中静默改写。外观（短发、墨镜等）依各场景区分，不混成单一固定穿搭。
- **本 Pilot 状态：** 不进入第一章开场段镜头；观察室中出现的是未在开场具名的短发女性观察者，不应直接标成陈菁，除非负责人明确采用小说信息确认其身份。

## 5. 人物可见性与同框规范

文本副本呈现了视角差异：第一章的监视者从外部看到陆辛独处；第七章“二号”能够看见妹妹；同章陈菁对陆辛提出家人可能是其想象的判断。前两项是场景证据，后者是角色判断；三者尚不能单独决定全书本体机制。暂按以下检查项处理：

1. 原文核对：谁能看见谁？是常态、特定条件，还是特定视角？
2. 画面设定：镜头显示的是客观场景、陆辛的主观感知，还是观众可见但场内他人不可见的形象？每镜头明确选择。
3. 互动检查：若家人接触物体、造成阴影/反射/声音或改变环境，必须确认原著规则允许。
4. 反应检查：背景人物是否对该角色作出反应；其反应必须与本镜头设定一致。
5. 剪辑检查：反打和越轴不得无意把主观信息转成客观信息。

每个镜头的角色栏至少写出：`画面可见角色 / 场内可见角色 / 当前主观视点 / 可互动对象`。

## 6. 一致性资产清单与版本

首轮不是批量生成 100–300 张。先建立足以验证角色识别的最小角色包；数量随镜头实际需要决定。

| 资产 | 必需字段 | 用途 |
|---|---|---|
| 角色基准立绘 | 正、侧、背；比例尺；服装版本；批准版本 | 锁定剪影与服装结构 |
| 面部组 | 正面与三分之二角度；中性、警觉、恐惧、克制反应等（仅取角色允许表情） | 关键帧与近景统一 |
| 服装/道具组 | 单件视图、穿戴视图、材质与颜色说明 | 镜头间检查穿帮 |
| 动作参考 | 起始/过程/结束姿态；接触点；运动方向；速度提示 | 动画或 I2V 动作约束 |
| 尺度与同框组 | 两角色相对身高/距离/遮挡关系 | 防止同框比例漂移 |
| 负向约束 | 不得出现的颜色、配件、发型/轮廓变化及其他错误 | 生成与审片清单 |

建议文件名：`CHAR-LUXIN__turnaround__v01.png`。使用项目相对路径保存；外部参考需另记来源、授权状态和哈希。批准后的基准图不被模型输出覆盖。

## 7. 角色一致性审核

对每个最终镜头检查：

- 轮廓、脸部识别点、发型、服装层次和固定道具与批准参考一致。
- 表情与肢体动作符合分镜状态，不在镜头间无故改变情绪或朝向。
- 角色数量、遮挡、左右位置和视线方向延续上一镜头。
- 可见性、反射、阴影、接触与背景反应符合该镜头声明的视点规则。
- 若无法从静帧判断运动或状态转换，将其标为 `UNVERIFIED`，不能凭单帧通过。

发现问题时登记 `镜头 ID / 时间点 / 错误类型 / 来源或参考图 / 可执行修复 / 重审要求`；优先局部返修，禁止因一个镜头错误就不加分析地重生成整段。

## 8. 冻结条件

- 每个出场人物的身份与行为均绑定到章节锚点；全书本体解释仍按剧情揭示范围管理。
- 主角与 Pilot 关键配角已有绑定版本的基准图；模型、种子或资产版本记录清楚。
- 不参与本版的角色明确标为未启用，避免生成系统自动补出。
- 所有 `CREATIVE_PROPOSAL` 均未被误写成原著事实。
