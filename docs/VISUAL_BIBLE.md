# 《从红月开始》Visual Bible

**版本：** v0.2 · 原文副本核对版/视觉方向提案

**状态：** 已用用户提供 TXT 副本第一章的场景描写校准初始视觉方向；副本版本尚未认证，视觉资产仍待设计/批准。

**用途：** 为概念帧、分镜、Animatic 和后续 ComfyUI 工作流提供统一的审美约束与审片标准。

## 1. 文本视觉锚点

依据用户提供的 `../../1-2203151F522.zip` 内 TXT 副本（GBK/CP936；ZIP SHA-256 `611A8B71474F1E03E395334F060EBFE42CCC157D46C2725193B1E9B88325A1C3`）：

| 来源锚点 | 文本确认的可视/可听信息 | 视觉应用边界 |
|---|---|---|
| 第一章《回家》开篇 | 暗红月亮压在高楼上；锈迹明显的暗色环城列车；昏暗车厢、月亮台站 | 可建立红月、城市层叠、列车与通勤的识别元素；城市的精确建筑样式仍由制作设计 |
| 第一章出站/回家路 | 霓虹使雨后街道呈多种颜色；破旧楼房、坏电梯、楼梯和厚重屋门 | **不把外景全部压成黑灰绿。** 多色霓虹和红月共存，饱和度/面积由本项目调色方案控制 |
| 第一章进屋 | 冷清走廊与温暖柔和的室内形成反差；厨房有炖煮食物和蒸汽 | 可用由冷到暖的光色切换建立“家”的表层安全感 |
| 第一章家庭晚饭段 | 妹妹、小熊、电话、厨房剁骨、餐桌与家人冲突并置；叙事呈现日常和异常的不协调 | 可以用节奏、反应和空间声音表达不安；不必增加怪物化身体特写或额外血腥细节 |
| 第一章观察室段 | 外部人员以望远镜观察；他们看到陆辛独自在屋内，而空间/家具表现出剧烈扰动 | 这是该场景的外部观察视角，不等于所有人永远看不到家人；与第七章另有角色看见妹妹的文本并存 |

## 2. 创作目标

以二维人物和 2.5D 空间关系为主要探索方向，用文本确认的“红月城市通勤 → 冷走廊/暖室内 → 家庭行为失衡 → 外部观察”构成首个视觉段落。红色是稳定世界母题之一，但不宣称它是全片唯一高饱和色；开篇另有多色霓虹。

希望观众先相信屋内是温暖日常，再因行为、空间声音和旁观视角之间的不一致感到不安。开篇的家庭场景尚未被直接定义为“精神污染”，污染等级 `P0–P3` 是制作标尺，不是原著对家人的分类。AI 生成中的随机瑕疵不是设计效果；只有在分镜中明确指定、能稳定重现并通过审核的异常，才算有意艺术表达。

## 3. 风格护栏

| 层面 | 初始提案 `CREATIVE_PROPOSAL` | 禁止的错误推断 |
|---|---|---|
| 角色 | 以二维线稿/色块角色为基线；轮廓、服装与表情优先于材质炫技 | 不把低细节、畸形手脸、肢体漂移称为“AI 风格” |
| 场景 | 2.5D 前/中/后景，保留清楚的空间锚点 | 不因恐怖感需要而无记录地改变门窗、楼层与方向 |
| 城市常态 | 锈暗列车、雨后街巷和多色霓虹；冷暖/色相对比使城市显得怪异 | 不得覆盖掉原文的多色霓虹，或把青港具体建筑风格说成原文定论 |
| 家庭室内 | 开始时温暖柔和，随着场景推进由行为、声音和构图造成不安 | 不把暖光等同于家庭安全/良善；颜色是镜头提案 |
| 红色 | 暗红月亮是开篇明确母题；红色可出现在天象与局部细节 | 不把血色、红唇、反光等元素扩展成每镜同一种“污染红”；精确色值仍待设计 |
| 污染 | 以透视、重复、延迟、比例和剪辑变化分级表达 | 不用任意闪烁/撕裂遮盖生成缺陷或叙事不清 |
| 镜头 | 正常阶段以稳定轴线建立空间，异常阶段有控制地破坏预期 | 不把“手持抖动/快速剪辑”当作默认恐怖解决方案 |
| 声音 | 留白、环境底噪、远近关系与重复语句作为提案 | 不将声压、失真和低频堆叠等同于恐怖氛围 |

## 4. 色彩与光线

本版不冻结具体 HEX 色值。待完成风格帧后，建立并绑定调色板版本。先采用关系性规则：

- **城市外景：** 红月之外，雨后霓虹呈多色；可通过暗色列车、湿润路面和层叠高楼控制画面密度。不要套用“80% 灰黑、只留红色”的旧提案。
- **归家过渡：** 站台、街巷、旧楼梯与门口逐渐减弱开放空间的亮色，进屋后转入柔暖室内；色温变化用于建立场景反差，不宣称为世界规则。
- **家庭异常：** 先保持暖色场景结构，再让人物动作、声音错位和镜头停顿造成不安；不用随机红染代替叙事。
- **红色焦点：** 红月是来源明确的视觉元素；局部反光、唇色、血迹等只按对应原文锚点与镜头需要处理，避免误把单次道具/细节变成全局污染编码。
- **污染升级：** 只有故事明确确认某行为/现象与污染相关后，才在镜头注册表中绑定污染级别；家庭场景可标“心理/认知悬念”，不可由视觉设计擅自判定为污染。
- **恢复常态：** 通过构图稳定、声音回归和场景光色过渡来恢复；不能仅靠切镜导致状态无解释复位。

### 污染呈现等级（概念工具，不是原著能力规则）

| 级别 | 视觉行为 | 声音/剪辑候选 | 验收重点 |
|---|---|---|---|
| `P0` 常态 | 稳定透视、连续空间、动作无循环异常 | 环境声自然，节奏留白 | 空间与角色建立清楚 |
| `P1` 疑点 | 单一影子/倒影短暂不同步；远处重复形状 | 轻微重复、环境声间隔异常 | 异常局部且观众可察觉，不抢戏 |
| `P2` 失衡 | 纵深渐变、重复背景、尺度或消失点偏移 | 广播/环境音重复，镜头停留稍长 | 异常跨镜头连续，核心空间锚点仍可追踪 |
| `P3` 危险 | 仅指定区域出现非欧式透视或局部时间断裂 | 节奏断点/短暂静默；慎用瞬态 | 观众仍能读懂人物位置与动作因果 |

每次污染效果记为：`效果 ID / 级别 / 画面区域 / 首次出现帧 / 持续时间 / 可见主体 / 延续镜头 / 退出条件`。

## 5. 镜头与空间语法

- **建立镜头：** 明确门、墙、走廊、窗或灯等固定空间锚点，方便之后表现尺度变化。
- **主角镜头：** 景别、视线高度和运动幅度服务人物当前状态。陆辛的视角尚未从原文确认，不能默认全片均为主观镜头。
- **家人出场：** 运用 Character Bible 中的角色专属提案前，先核实人物外观、出场规则和场内可见性。第一章观察室段的“陆辛独处”与第七章“二号能看见妹妹”均须保留；不能用单一滤镜解释所有视角。
- **污染镜头：** 一次主要改变一个维度（空间/时间/重复/比例/色彩），其他维度作为后续升级；防止多种效果同叠后不可读。
- **动作镜头：** 清楚标出动作准备、启动、路径、接触/避让和收势。关键动作采用可核验的起始/结束关键帧。
- **剪辑：** 运动方向和视线关系跨镜头保持一致；若故意跳轴、跳时或跳帧，注明目的与观众应感知到的差异。

## 6. 声音方向

完整音频生产规格、Voice Bible、对白时间轴、音效/配乐 ID、混音与 Audio QA 见 [AUDIO_BIBLE.md](AUDIO_BIBLE.md)。本 Visual Bible 只锁定画面与声音透视之间的协作接口。当前 90 秒 Pilot 无可辨人物对白，但有环境声、电话/争执的不可辨声纹提案和妹妹的非语言哭笑 cue。

- 每个镜头明确声音视点是场景内、角色主观、画外观察还是纯配乐，并与该镜头实际画面视角相符。
- 常态建立连续环境底噪与可定位声源；如果呈现重复、断续、距离错位或静默，必须有分镜事件/来源依据。第一章家庭异常不擅自标为精神污染。
- 不增加未经核实的对白、广播内容、专名或字幕；音效不替代画面因果，静音观看仍需能读懂动作。
- 对白或非语言声音触发角色面部动作时，需绑定最终音频时间轴；模型不得自行猜口型。
- 音频技术检查、对白可懂度、字幕/口型同步与连续主观听审分项记录；波形/数值通过不等于审美 PASS。

## 7. 资产与提示词协议

提示词使用受控 ID 组合，而非仅靠长段自然语言描述：

```text
CHAR:LUXIN@v01
COSTUME:<已批准版本>
LOCATION:<场景资产 ID>@vXX
LIGHT:<光线方案 ID>@vXX
POLLUTION:P0..P3 + 指定效果 ID
CAMERA:<景别/视角/运动>
ACTION:<起点> -> <终点>
CONTINUITY:<承接镜头与锁定要素>
```

`CHAR:LUXIN` 等 ID 只是资产索引，不能自动保证模型识别或角色一致。每次生产还需明确绑定参考图、工作流/模型版本、关键参数、种子（若适用）、输入/输出文件哈希和生成任务 ID。提示词、工作流和输出均应保存项目相对路径；模型及工具应从项目配置读取，不将本机绝对路径写入业务文件。

## 8. 生成物来源与镜头版本

每个镜头保留最小来源记录：

```text
shot_id / shot_revision
分镜版本与镜头时长
提示词与负向约束
参考资产 ID + 文件哈希 + 权利/许可状态
模型、工作流及版本；关键生成参数/种子
源图、视频与音频文件相对路径及哈希
剪辑/合成版本
视觉、连续性、声音审核状态与审核证据
返修原因、变化范围与复审结论
```

审核结论绑定具体镜头版本或最终成片哈希。任何实质修改使相应审核失效；不能把上一版 PASS 直接带到新版本。

## 9. 逐镜审片与缺陷分类

| 级别 | 定义 | 行动 |
|---|---|---|
| `HARD` | 关键角色/空间严重变形、错误角色或多余肢体、无意乱码/闪帧、动作因果不可读、与来源明确矛盾 | 必须修复并复审；不可交付 |
| `MAJOR` | 角色识别或镜头意图被实质削弱；明显穿帮；污染效果与设定/相邻镜头冲突 | 返修并复审；不可用总评分抵消 |
| `MINOR` | 不影响理解的边缘细节、轻微节奏或色彩偏差 | 记录，可按优先级处理 |
| `UNVERIFIED` | 证据不足，例如只看静帧而未查看运动/听音频 | 保持未验证状态，不得计为 PASS |

每条问题包含时间点、画面证据、预期表现、实际差异、修复范围和复审方法。视觉静帧审核、连续运动审核、音频审核、技术解码审核分别记录；任一层不得冒充全片综合通过。

## 10. 首轮风格验证与验收

优先制作小型 style frame 和单个连续 10–15 秒镜头组，不一次渲染完整 90 秒。先验证：

1. 红月/多色霓虹城市与暗色环城列车是否共同可读，不抹平成单色废土。
2. 冷走廊至暖室内是否建立归家反差，家庭后段是否靠行为与视角产生不安。
3. 陆辛与妹妹的可识别轮廓、服装版本及表演差异（视觉设计审核后）。
4. 外部观察镜头能否清楚表达“观察者看到陆辛独处”，又不暗示全书可见性规则已经解决。
5. 角色/背景/运动的二维与 2.5D 融合是否统一；连续镜头的空间锚点是否稳定。

通过条件：无 `HARD` / `MAJOR` 开放问题；动态效果经连续观看；失败镜头可定位到具体原因并局部修复；人物与世界的视觉主张由负责人确认。此通过只针对对应验证素材和版本。

## 11. 与现有工作区经验的关系

工作区的 `google-documentary` 项目已有按镜头登记来源、版本哈希和分层事实/故事/视觉/连续性审核的实践；`perfume-director` 已验证参考库、设计规格、ComfyUI 合成与有限轮次审阅闭环。这两类经验可复用的是**资产登记与分层审核方法**，并不证明香水海报的角色一致性方案已适用于动画，也不替代本项目的模型、显存与授权验证。
